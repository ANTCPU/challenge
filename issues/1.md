[d8 · Week 2] Plan Your Build — Document Before You Code

## Gate d8 — Week 2 Brief · +30%

Week 2 is execution. Before you write a single line of code,
document your plan. This is the build rule across the entire
antcpu codebase:

> Observe → Document → Discuss → Build.
> Code follows the document. Never the other way around.

---

## Your Task

Fork this repo: `github.com/ANTCPU/challenge`

Create a file called `PLAN.md` in your fork. Answer these:

- **What are you building?** One sentence.
- **Why did you choose it?** What problem does it solve?
- **How will you structure it?** Folders, files, approach.
- **What AI tools will you use and how?** Co-pilot, not crutch.
- **What does done look like?** How will you know it works?

One page. Clear thinking. No fluff.
