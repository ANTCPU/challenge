# Starter Ticket — Document Your Week 3 Plan

**Tier:** Starter · Gates done: 2+
**Track:** Dev (Marketing: observe + share)
**Week:** 3

## The Task
Create a file called `PLAN.md` in your fork.
Write your Week 3 build plan in it.
Open a PR with it.

## What PLAN.md Should Include
- What you are building this week
- Why you picked it
- What files you expect to touch
- How you will use AI as a co-pilot
- What done looks like

## Steps
1. Fork this repo (if not already done)
2. Create branch: `your-handle/week3-plan`
3. Create PLAN.md with the sections above
4. Open a PR titled: `[Plan] YourHandle Week 3 Build Plan`
